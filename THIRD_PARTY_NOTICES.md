# Dependencias de terceros

ToolHub utiliza bibliotecas de terceros para algunas funciones.

## pdf-lib
- Versión: 1.17.1
- Proyecto: https://github.com/Hopding/pdf-lib
- Licencia: MIT

## PDF.js / pdfjs-dist
- Versión: 3.11.174
- Proyecto: https://github.com/mozilla/pdf.js
- Licencia: Apache-2.0

## JSZip
- Versión: 3.10.1
- Proyecto: https://github.com/Stuk/jszip
- Licencia: MIT OR GPL-3.0-or-later

Las páginas PDF cargan estas bibliotecas mediante URLs versionadas de jsDelivr.


## Ollama (opcional)
ToolHub puede conectarse a una instalación local de Ollama mediante su API local. Ollama y los modelos utilizados pertenecen a sus respectivos autores y no se incluyen en este ZIP.
