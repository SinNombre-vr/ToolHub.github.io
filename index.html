PRIVACIDAD Y PROTECCIÓN DE DATOS

Antes de continuar

Antes de utilizar esta web debes leer esta información, especialmente si vas a manipular documentos PDF que puedan contener datos personales.

Tratamiento de PDF
Las herramientas PDF están diseñadas para procesar los archivos localmente en tu navegador, sin enviarlos ni almacenarlos en servidores de esta web.
Finalidad
Ejecutar únicamente la operación sobre el documento que el usuario solicite.
Normativa de referencia
Reglamento (UE) 2016/679 (RGPD) y Ley Orgánica 3/2018 (LOPDGDD).
Recordatorio de aceptación
La web guarda únicamente en este navegador una marca local que recuerda que este aviso ya fue aceptado, para no volver a mostrarlo en visitas posteriores.
Funciones de IA opcionales
El Generador de MatCap funciona localmente por defecto. El asistente gratuito sin modelo no envía datos; Ollama puede procesar el texto en tu propio PC. Solo si eliges OpenAI se envían a esa API el texto, la configuración actual y la memoria de preferencias seleccionada. No se envían imágenes ni archivos mediante esa función.

Si un PDF contiene datos personales, información confidencial o datos de terceros, asegúrate de tener autorización o una base jurídica válida para utilizarlo. No proceses más información de la necesaria.

STEAMVR · UTILIDAD

OVR Advanced Settings

¿Qué es?

Es una aplicación de overlay para SteamVR que añade ajustes y utilidades accesibles desde el dashboard de VR.

Instalación

  1. Ten Steam y SteamVR instalados.
  2. Abre OVR Advanced Settings en Steam.
  3. Instálalo y ejecútalo junto a SteamVR.
  4. Dentro de VR abre el dashboard de SteamVR y busca OVR Advanced Settings.

Funciones útiles

  • Space Drag: desplazar virtualmente tu posición.
  • Space Turn: girar el espacio virtual.
  • Fix Floor: reajustar la altura del suelo.
  • Push-To-Talk / Push-To-Mute: controlar el micrófono.
  • Brillo, bindings por aplicación y otras utilidades de SteamVR.
Consejo: cambia una opción cada vez, especialmente las relacionadas con movimiento del espacio.
Abrir en Steam ↗
PCVR · CONECTIVIDAD

Virtual Desktop

Importante: la versión de Steam es Virtual Desktop Classic y está orientada a visores PCVR como Rift/Rift S, HTC Vive, Valve Index y Windows Mixed Reality. No es la versión para Meta Quest ni Pico.

Para Meta Quest / Pico y otros standalone

  1. Instala la versión standalone correspondiente a tu visor.
  2. Instala Virtual Desktop Streamer en el PC desde la web oficial.
  3. Conecta el PC al router por Ethernet siempre que sea posible.
  4. Conecta el visor a una red Wi-Fi rápida y estable.
  5. Abre Virtual Desktop en el visor y conéctate al PC.
  6. Para PCVR, inicia los juegos desde la sección de juegos de Virtual Desktop cuando corresponda.

Red recomendada

  • PC conectado por Ethernet al router.
  • Wi-Fi de 5 GHz AC/AX como mínimo según la documentación oficial.
  • Evita redes de invitados o redes distintas entre PC y visor.
  • Si hay cortes, revisa firewall, VPN y antivirus.

Versión de Steam

Si usas un visor PCVR compatible con Virtual Desktop Classic, puedes abrir la ficha oficial de Steam desde el botón inferior.
