# Profile usability checks

- Guest header: `Login / Register`.
- Community login: header switches to chosen display name or username.
- Login and registration forms are mutually exclusive.
- Signed-in user lands on the personal profile dashboard.
- Studio creations and asset contributions use separate counters.
- Existing 32 assets are attributed to Owner.
- Owner badge: crown emblem. Admin badge: diamond emblem.
- Owner-only review panel supports pending/all/approved/rejected filters, approve/reject, and reputation assignment.
