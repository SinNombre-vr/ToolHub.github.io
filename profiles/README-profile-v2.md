# ToolHub Profile v2

- La sesión comunitaria usa `toolhub-community-auth-v2` y queda separada del acceso administrativo.
- El header muestra `Login / Register` sin sesión y el nombre visible/usuario cuando la cuenta comunitaria está iniciada.
- Los assets guardan `submitted_by` cuando se publican desde una cuenta autenticada.
- El perfil distingue creaciones de Studio de assets aportados.
- Owner y Admin muestran insignia propia en el perfil.
- Solo Owner recibe el panel de revisión de contribuciones y puede aprobar/rechazar propuestas y asignar reputación.
