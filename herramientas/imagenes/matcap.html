PRIVACIDAD Y PROTECCIÓN DE DATOS

Antes de continuar

El generador de MatCap funciona localmente. La textura overlay y los PNG generados no se envían a ToolHub.

Modo local
Los controles, presets y el asistente local sin modelo se ejecutan en el navegador.
Ollama
Si lo eliges, el texto se procesa con un modelo instalado en tu propio PC mediante el servidor local de ToolHub.
OpenAI
Solo si eliges ese modo, el texto y los parámetros del MatCap se envían a la API configurada.
Normativa de referencia
Reglamento (UE) 2016/679 (RGPD) y Ley Orgánica 3/2018 (LOPDGDD).
