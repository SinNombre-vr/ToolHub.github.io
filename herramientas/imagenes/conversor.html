PRIVACIDAD Y PROTECCIÓN DE DATOS

Antes de continuar

Antes de utilizar esta web debes leer esta información, especialmente si vas a manipular documentos PDF que puedan contener datos personales.

Tratamiento de PDF
Las herramientas PDF están diseñadas para procesar los archivos localmente en tu navegador, sin enviarlos ni almacenarlos en servidores de esta web.
Tratamiento de imágenes
Las herramientas de imagen de esta versión también procesan los archivos localmente en el navegador.
Finalidad
Ejecutar únicamente la operación sobre el archivo que el usuario solicite.
Normativa de referencia
Reglamento (UE) 2016/679 (RGPD) y Ley Orgánica 3/2018 (LOPDGDD).
Recordatorio de aceptación
La web guarda únicamente en este navegador una marca local que recuerda que este aviso ya fue aceptado.
Funciones de IA opcionales
El Generador de MatCap funciona localmente por defecto. El modo gratuito no envía datos y Ollama puede ejecutarse en el propio PC. Solo si seleccionas OpenAI se envían a esa API el texto, la configuración actual y la memoria seleccionada; no se envían imágenes ni archivos.

Si un archivo contiene datos personales, información confidencial o datos de terceros, asegúrate de tener autorización o una base jurídica válida para utilizarlo.
