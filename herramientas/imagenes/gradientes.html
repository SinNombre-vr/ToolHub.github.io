Funciones de IA opcionales
El Generador de MatCap funciona localmente por defecto. El modo gratuito no envía datos y Ollama puede ejecutarse en el propio PC. Solo si seleccionas OpenAI se envían a esa API el texto, la configuración actual y la memoria seleccionada; no se envían imágenes ni archivos.

Si un archivo contiene datos personales, información confidencial o datos de terceros, asegúrate de tener autorización o una base jurídica válida para utilizarlo.
