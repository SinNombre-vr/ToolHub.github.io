Optimizar PDF

Reduce el tamaño de un PDF con un modo ligero o una compresión fuerte basada en imágenes.

🔒 PDF procesado localmente
Modo de compatibilidad: si un PDF tiene restricciones internas, ToolHub reconstruirá automáticamente una copia procesable en el navegador. En ese caso la copia puede perder texto seleccionable porque las páginas se regeneran visualmente. Los PDF con contraseña siguen necesitando desbloqueo previo.
Nota: si el PDF está restringido, ToolHub primero crea una copia compatible en alta calidad. Después se aplica el tipo de optimización que elijas aquí.

PRIVACIDAD Y PROTECCIÓN DE DATOS

Antes de continuar

Antes de utilizar esta web debes leer esta información, especialmente si vas a manipular documentos PDF que puedan contener datos personales.

Tratamiento de PDF
Las herramientas PDF de ToolHub procesan el contenido localmente en tu navegador. Los PDF no se envían ni se almacenan en servidores de ToolHub.
Librerías técnicas
La versión web carga librerías JavaScript desde jsDelivr para procesar PDF. Esas librerías se descargan al navegador; ToolHub no les envía tus documentos.
Finalidad
Ejecutar únicamente la operación sobre el archivo que el usuario solicite.
Normativa de referencia
Reglamento (UE) 2016/679 (RGPD) y Ley Orgánica 3/2018 (LOPDGDD).
Recordatorio de aceptación
La web guarda en este navegador una marca local para recordar que este aviso ya fue aceptado.

Si un PDF contiene datos personales, información confidencial o datos de terceros, asegúrate de tener autorización o una base jurídica válida para utilizarlo.
