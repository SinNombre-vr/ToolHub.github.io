🧩 Versión

Empieza por la versión correcta de Unity

🟣 VRChat actual: la versión soportada es Unity 2022.3.22f1. La forma más sencilla de crear proyectos correctos es usar VRChat Creator Companion.
🟡 No actualices el editor porque Unity Hub diga que existe uno más nuevo: VRChat advierte que subir contenido desde una versión no soportada puede hacer que no cargue correctamente.
🪟 Ventanas

Las partes que debes reconocer

Hierarchy

Lista de GameObjects de la Scene. Aquí ves padres, hijos y la estructura real del avatar.

Scene

Vista de edición 3D. Sirve para mover, rotar, escalar y revisar visualmente objetos.

Inspector

Muestra componentes y propiedades del objeto o asset seleccionado.

Project

Navegador de archivos dentro de Assets/Packages: materiales, texturas, animaciones, prefabs, etc.

Console

Errores, warnings y logs. Cuando el SDK deja de funcionar, empieza aquí.

Game

Vista renderizada por una cámara durante Play Mode. No es lo mismo que Scene View.

🎞️ Animation vs Animator

No son la misma ventana

🎬

Animation

Edita Animation Clips: curvas, keyframes y propiedades que cambian con el tiempo.

🧠

Animator

Organiza estados, transiciones y parámetros que deciden qué Animation Clip se reproduce.

🎛️

FX Controller

En avatares VRChat suele usarse para toggles, cambios de material, blendshapes y efectos.

🧰 VRChat SDK

Qué papel tiene el SDK

1

Descriptor

El avatar necesita un VRC Avatar Descriptor correctamente configurado.

2

Builder

El SDK revisa errores, performance y requisitos antes de Build/Test/Publish.

3

Platform

PC y Android/Quest pueden tener builds y materiales distintos.

4

Build & Test

Prueba antes de publicar; VRChat también ofrece testing para Android en dispositivos compatibles.

📁 Organización

Una estructura simple evita perder archivos

Assets/ ├─ Avatar/ │ ├─ Materials/ │ ├─ Textures/ │ ├─ Animations/ │ ├─ Controllers/ │ └─ Prefabs/ ├─ Packages / Tools └─ ThirdParty/
