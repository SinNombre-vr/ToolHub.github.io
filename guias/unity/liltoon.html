🎨 Resumen

lilToon en una frase

lilToon es un shader toon rico en funciones para avatares, con presets, herramientas de color, normales, MatCap, emisión, outline, dissolve y optimización automática de variantes.

🪄
Presets

Permiten guardar y reaplicar configuraciones de materiales de forma rápida.

🎭
Estilo

Sombras, rim, MatCap, gloss, outline y múltiples controles de color.

⚡
Optimización

El editor puede eliminar funciones no utilizadas de las variantes generadas.

📦 Instalación

Instalar y mantener limpio el proyecto

1

Añade el repositorio VPM

La instalación por VCC/VPM es la ruta más cómoda para mantener versiones modernas.

2

No mezcles carpetas antiguas

Si aparecen errores tras actualizaciones, revisa que no existan copias viejas del shader dentro de Assets.

3

Haz backup

Antes de migrar entre versiones grandes, duplica el proyecto o crea un backup desde VCC.

🧱 Material

Orden práctico de configuración

Main Color

Empieza por textura y color base. Ajusta primero la apariencia general antes de añadir efectos.

Shadows

Controla separación de zonas iluminadas y oscuras; es la base del estilo toon.

Normal Map

Modifica cómo reaccionan sombra, gloss, MatCap, rim y otros módulos a la superficie.

MatCap / Rim

Añade reflejos estilizados y luz de borde. Son potentes, pero conviene usarlos con intención.

Emission

Puede usar máscaras, UV scroll y cambios de color/tiempo para efectos luminosos.

Rendering

Opaque, Cutout, Transparent y variantes especiales cambian coste y orden de render.

🧭 Normales

El Normal Map no es solo “relieve”

lilToon documenta que el Normal Map modifica cómo responden sombras, backlight, gloss, MatCap, rim, glitter, AudioLink, refraction y otras funciones.

🔵 Uso común: un Normal Map principal para la forma general y otro secundario para microdetalle, por ejemplo piel, tela o metal cepillado.
⚡ Optimización

No necesitas activar todo

  • Usa Opaque si no necesitas transparencia.
  • Evita doble cara si la geometría está correctamente construida y no necesitas ver ambas caras.
  • Desactiva módulos que no aporten nada visible.
  • Reduce resoluciones y reutiliza máscaras.
  • Revisa material slots del avatar además del coste del shader.
🧪 Custom Shader

lilToon también permite extensiones personalizadas

La documentación oficial incluye una plantilla para custom shaders basada en archivos HLSL, bloques de propiedades e inspector personalizado.

Template/ ├─ Shaders/custom.hlsl ├─ Shaders/custom_insert.hlsl ├─ Shaders/lilCustomShaderDatas.lilblock ├─ Shaders/lilCustomShaderProperties.lilblock └─ Editor/CustomInspector.cs
🟣 Para empezar: si solo quieres un efecto sencillo, primero intenta hacerlo con las funciones integradas de lilToon antes de crear una variante custom.
📱 Quest / Android

Shader móvil separado

Igual que con otros shaders personalizados, los avatares Android/Quest de VRChat deben usar los shaders móviles permitidos por el SDK. Mantén una versión móvil del material.

🛠 Diagnóstico

Errores frecuentes

La documentación oficial recomienda comprobar Console, reinstalar la versión actual y evitar que convivan copias de versiones diferentes.
Comprueba que el shader exista y compile. Si el proyecto tiene errores de scripts, Unity también puede impedir que el SDK funcione correctamente.
Prueba distintos entornos de iluminación. Shading, rim, MatCap y emission responden de forma diferente según el mundo.
