🧪 Concepto

Qué hace realmente un shader

Un shader es código que decide cómo se dibuja una superficie: qué color sale, cómo responde a normales, luz, texturas, transparencia y tiempo.

⌨️ Crear

Partes básicas de un shader personalizado

Properties

Parámetros visibles en el Inspector del Material.

Vertex stage

Procesa vértices y puede modificar posición, normales o datos enviados al fragment.

Fragment stage

Calcula el color final de los píxeles/fragments.

Render State

Blend, culling, depth, queue y otras decisiones de render.

⚡ Rendimiento

Qué suele encarecer un shader

  • Múltiples passes para outline, grab pass o efectos adicionales.
  • Transparencia y mucho overdraw.
  • Muestras de muchas texturas por píxel.
  • Cálculos complejos repetidos en fragment shader.
  • Efectos que no aportan nada visible pero permanecen activos.
📱 Quest / Android

Restricción crítica para avatares

VRChat solo permite en avatares Android/Quest los shaders móviles suministrados por el SDK. Un shader personalizado generado para PC no debe considerarse automáticamente compatible con Quest.

🔴 Regla: crea una variante/material móvil separado cuando prepares el avatar para Android/Quest.
🛠 Problemas

Cuando el shader no funciona

Unity no encuentra o no puede compilar el shader. Abre Console y corrige el primer error real, no los veinte errores secundarios.
Comprueba propiedades, sampler, UV y si la textura está realmente asignada.
